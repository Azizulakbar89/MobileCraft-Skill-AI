## 🛑 The Problem: What is "AI Slop"?

When you ask ChatGPT, Claude, or standard Cursor prompts to *"build a mobile frontend"*, you almost always get **AI Slop**:

| Visual & Architecture Area | ❌ Standard LLM "AI Slop" | ⚡ MobileCraft Standard |
| :--- | :--- | :--- |
| **Color & Theme** | Generic purple-to-pink saturated gradients | Strict dark-mode tokens (`#080A0E`, `#121620`, `#1A1F2B`) with APCA-verified text contrast |
| **Data Fetching** | Raw `useEffect()` + `useState()` causing memory leaks & flickers | **TanStack Query (React Query)** with caching, optimistic updates & skeletons |
| **Form Handling** | 10 scattered `useState()` variables with zero validation | **React Hook Form + Zod/Valibot** with type-safe inline error states |
| **Thumb Ergonomics** | Back buttons & CTAs shoved into inaccessible top corners | **Thumb-Zone Law:** Primary actions locked to the bottom 40% of the screen |
| **Touch Targets** | Fragile 18px–24px buttons impossible to tap reliably | Strict **48pt–56pt** minimum touch target with 8pt concentric spacing |
| **State Architecture** | Prop drilling or unmanaged chaotic contexts | **Zustand** (global client) + **Jotai** (atomic micro-state) |
| **Border Radii** | Arbitrary mismatched corners | **Concentric Radii Formula:** $R_{\text{inner}} = R_{\text{outer}} - \text{padding}$ |
| **Animations** | Janky CSS keyframes that drop frames on mobile | **60–120 FPS Spring Physics** via Motion / RN Reanimated / Flutter Curves |

## 💡 Production Code Blueprint Examples

### 1. Form Validation without Slop (React Hook Form + Zod)
```tsx
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { z } from 'zod';

const bookingSchema = z.object({
  fullName: z.string().min(3, 'Nama minimal 3 karakter'),
  tickets: z.number().min(1, 'Pilih minimal 1 tiket').max(10, 'Maksimal 10 tiket'),
});

type BookingInput = z.infer<typeof bookingSchema>;

export function BookingSheet() {
  const { register, handleSubmit, formState: { errors, isSubmitting } } = useForm<BookingInput>({
    resolver: zodResolver(bookingSchema),
  });

  return (
    <form onSubmit={handleSubmit(async (data) => console.log(data))} className="space-y-4">
      <div>
        <label className="text-xs font-bold text-slate-300">Nama Lengkap</label>
        <input {...register('fullName')} className="w-full h-12 rounded-xl bg-slate-900 px-4 text-sm text-white border border-slate-700" />
        {errors.fullName && <p className="text-xs text-red-400 mt-1">{errors.fullName.message}</p>}
      </div>
      <button disabled={isSubmitting} className="w-full h-13 rounded-2xl bg-white text-black font-extrabold text-sm active:scale-95 transition-transform">
        {isSubmitting ? 'Memproses...' : 'Konfirmasi Pemesanan'}
      </button>
    </form>
  );
}
```

### 2. Ergonomic Data Fetching (TanStack Query)
```tsx
import { useQuery } from '@tanstack/react-query';

export function MovieList() {
  const { data, isLoading, isError, refetch } = useQuery({
    queryKey: ['movies', 'trending'],
    queryFn: async () => (await fetch('/api/movies')).json(),
    staleTime: 1000 * 60 * 5, // 5 min cache
  });

  if (isLoading) return <MovieListSkeleton />;
  if (isError) return <ErrorRetry onRetry={() => refetch()} />;
  if (!data?.length) return <EmptyState label="Belum ada film tersedia" />;

  return (
    <div className="grid grid-cols-2 gap-3.5 pb-24">
      {data.map((m: any) => <MovieCard key={m.id} movie={m} />)}
    </div>
  );
}
```
