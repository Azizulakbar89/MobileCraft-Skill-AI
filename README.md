## ⚡ Quick Start (Install in 10 Seconds)

Simply clone or copy the rules folder into your project root:

```bash
# 1. Clone MobileCraft into your project
git clone https://github.com/Azizulakbar89/MobileCraft-Skill-AI.git temp-skill
cp -r temp-skill/.cursor temp-skill/.skills temp-skill/.github temp-skill/.windsurfrules ./
rm -rf temp-skill

# That's it! Your AI assistant is now 100% slop-proof.
```

Your AI assistant will **automatically detect** the rules when creating or editing code in React, Next.js, Vue, Nuxt, SvelteKit, React Native, Expo, Flutter, SwiftUI, and Jetpack Compose.


## 📚 Supported Libraries Matrix & Anti-Slop Rules

We love modern UI libraries, but only when used properly. MobileCraft forces AI agents to strip away their default boilerplate slop:

| UI Library | Primary Role | MobileCraft Slop-Proof Rule |
| :--- | :--- | :--- |
| **[daisyUI](https://daisyui.com/)** | Pure Tailwind component classes (Zero JS) | **Never** use default neon candy colors. Auto-maps semantic depth tokens (`canvas`, `surface`, `border-hairline`). |
| **[HeroUI](https://www.heroui.com/)** *(NextUI)* | React Aria + Tailwind with silky spring motion | **Never** stack muddy glassmorphism. Uses clean surface cards and native gesture physics. |
| **[Radix UI](https://www.radix-ui.com/) / [Headless UI](https://headlessui.com/)** | 100% Unstyled accessible primitives | Enforces $44\text{pt}+$ touch targets and bottom-docked interactive sheets. |
| **[Mantine](https://mantine.dev/)** | Full-featured library (100+ components) | Replaces desktop tables with grouped card lists and opens modals from the bottom on mobile. |
| **[Material UI (MUI)](https://mui.com/)** | Enterprise Google Material Design | Overrides generic `#1976d2` buttons with $16\text{px}+$ corner radii and subtle hairline borders. |
| **[Ant Design](https://ant.design/)** | Data-dense internal tools & dashboards | Replaces horizontal scroll tables with mobile cards; scales buttons to $44\text{pt}+$ thumb height. |

## 🤖 Multi-Agent Setup Guides

MobileCraft is designed to work natively across all leading AI coding assistants:

<details open>
<summary><b>1. 🖱️ Cursor IDE</b></summary>

* **Configuration:** `.cursor/rules/mobile-ui-core.mdc` & `mobile-motion-ergonomics.mdc`.
* **Globs:** Automatically triggers on `*.tsx`, `*.jsx`, `*.dart`, `*.swift`, `*.kt`, `*.vue`, `*.svelte`.
* **How to use:** Copy the `.cursor/` folder into your repository. Cursor will automatically apply concentric corner radii, Reanimated spring physics, and thumb-first ergonomics.
</details>

<details>
<summary><b>2. 🤖 Claude Code (Anthropic CLI)</b></summary>

* **Configuration:** `.skills/mobile-frontend-craft/SKILL.md` & `references/`.
* **How to use:** Copy the `.skills/` directory to your project root. Reference it in your `CLAUDE.md`:
  ```markdown
  Read and strictly adhere to .skills/mobile-frontend-craft/SKILL.md for all frontend and mobile tasks.
  ```
* **Output:** Claude Code follows a mandatory 4-phase audit before outputting any code, guaranteeing all 4 states (Skeleton Loading, Empty, Error, Overflow) are handled.
</details>

<details>
<summary><b>3. 🛸 Google Antigravity</b></summary>

* **Configuration:** `.skills/mobile-frontend-craft/SKILL.md`.
* **How to use:** Place in your workspace or in `~/.gemini/antigravity/skills/` for global availability.
* **Output:** Uses progressive disclosure to fetch design tokens, motion presets, and platform ergonomics on-demand.
</details>

<details>
<summary><b>4. 🌊 Windsurf IDE (Codeium)</b></summary>

* **Configuration:** `.windsurfrules`.
* **How to use:** Place `.windsurfrules` in your project root. Cascade will immediately enforce the 7 Core Pillars.
</details>

<details>
<summary><b>5. 🐙 GitHub Copilot</b></summary>

* **Configuration:** `.github/copilot-instructions.md`.
* **How to use:** Place the `.github/` folder in your project root. Copilot Chat and autocompletion will prioritize Zustand, TanStack Query, and safe area insets.
</details>
