## 🏛️ Daftar Teknologi & Stack yang Ditawarkan (7 Pilar Produksi)

MobileCraft memaksa AI Agent (Cursor, Claude Code, Antigravity, Windsurf, Copilot) untuk meninggalkan kode amatir dan **selalu menggunakan standar arsitektur 7 pilar industri**:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        THE 7 CORE PRODUCTION PILLARS                                  │
├────────────────────────────────┬───────────────────────────────────────────────────────┤
│ 1. Core & Meta-Frameworks      │ React / Next.js (App Router), Vue / Nuxt, SvelteKit,  │
│                                │ React Native (Expo), Flutter (Dart)                   │
├────────────────────────────────┼───────────────────────────────────────────────────────┤
│ 2. Styling & UI Components     │ Tailwind CSS, shadcn/ui & React Native Reusables,     │
│                                │ Headless UI / Radix / Ark UI, daisyUI, HeroUI, Mantine│
│                                │ Ant Design, Material UI (MUI)                         │
├────────────────────────────────┼───────────────────────────────────────────────────────┤
│ 3. State Management            │ Zustand (Client State), Jotai / Nanostores (Atomic),  │
│                                │ Redux Toolkit (Enterprise RTK)                        │
├────────────────────────────────┼───────────────────────────────────────────────────────┤
│ 4. Data Fetching & Server State│ TanStack Query (React Query), SWR, Ky / Axios + Hooks │
├────────────────────────────────┼───────────────────────────────────────────────────────┤
│ 5. Forms & Schema Validation   │ React Hook Form + Zod / Valibot                       │
├────────────────────────────────┼───────────────────────────────────────────────────────┤

├────────────────────────────────┼───────────────────────────────────────────────────────┤

└────────────────────────────────┴───────────────────────────────────────────────────────┘
```

### 1. Core Framework & Meta-Framework (Fondasi)
* **React & Next.js:** Standar industri untuk web modern dengan dukungan Server-Side Rendering (SSR), React Server Components (RSC), dan App Router.
* **Vue & Nuxt:** Alternatif performa tinggi yang sangat intuitif dengan Composition API dan kurva belajar landai.
* **Svelte & SvelteKit:** Compiler-based framework yang menghasilkan ukuran bundle sangat kecil tanpa Virtual DOM.
* **React Native (Expo):** Pilihan utama untuk aplikasi mobile cross-platform berbasis ekosistem JavaScript/TypeScript.
* **Flutter (Dart):** Framework mobile cross-platform berkinerja tinggi yang dikompilasi langsung ke machine code native (60–120 FPS mulus).

---

### 2. Styling & UI Component Libraries (Bebas Desain Kaku & Slop)
Pustaka komponen UI yang didukung dan dikonfigurasi khusus agar terbebas dari warna neon murahan:

| Nama Pustaka | Pendekatan Utama | Kelebihan & Peran di Skill Ini |
| :--- | :--- | :--- |
| [**daisyUI**](https://daisyui.com/) | Plugin kelas komponen untuk Tailwind CSS | Sangat ringan tanpa membawa JavaScript tambahan, mendukung multi-theme instan (dark/light/dracula) tanpa bloat. |
| [**HeroUI**](https://www.heroui.com/) *(NextUI)* | Pustaka komponen berbasis Tailwind & React Aria | Tampilan modern estetis dengan animasi halus bawaan yang siap pakai tanpa banyak konfigurasi rumit. |
| [**Radix UI**](https://www.radix-ui.com/) / [**Headless UI**](https://headlessui.com/) | Komponen headless (tanpa gaya bawaan) | Kebebasan desain 100% dari nol dengan logika aksesibilitas (WAI-ARIA, keyboard navigation) yang teruji. |
| [**Mantine**](https://mantine.dev/) | Pustaka komponen React lengkap *(full-featured)* | Menyediakan 100+ komponen kompleks seperti DataTable, Charts, Modal Managers, dan Rich Text Editor. |
| [**Material UI (MUI)**](https://mui.com/) | Sistem desain berbasis Google Material Design 3 | Ekosistem sangat matang dengan dokumentasi lengkap untuk aplikasi skala korporat dan form multi-step. |
| [**Ant Design**](https://ant.design/) | Sistem desain tingkat perusahaan *(enterprise)* | Sangat kuat untuk membangun dashboard admin, CRM, dan sistem internal padat data dengan tabel kompleks. |
| [**shadcn/ui**](https://ui.shadcn.com/) / [**RN Reusables**](https://react-native-reusables.vercel.app/) | Primitif copy-paste berbasis Radix & Tailwind | Kontrol penuh atas kode sumber komponen tanpa ketergantungan paket node_modules eksternal yang kaku. |

---

### 3. State Management (Pengelolaan Data Aplikasi)
* **Zustand:** Solusi default untuk client state global yang ringan, minim boilerplate, dan mudah diintegrasikan tanpa context provider hell.
* **Jotai / Nanostores:** Pendekatan *atomic state* granular yang ideal jika banyak micro-komponen saling bergantung tanpa memicu re-render massal.
* **Redux Toolkit (RTK):** Digunakan pada aplikasi berskala enterprise yang membutuhkan pola arsitektur ketat dan time-travel debugging.

---

### 4. Data Fetching & Server State
> 🛑 **Aturan Wajib Anti-Slop:** Dilarang keras melakukan fetch API di dalam raw `useEffect() + useState()`!
* **TanStack Query (React Query):** Standar emas untuk fetching data asinkron, caching otomatis, background revalidation, optimistic updates, dan infinite scrolling.
* **SWR:** Alternatif ringan buatan Vercel untuk strategi *stale-while-revalidate*.
* **Ky / Axios:** HTTP client dengan interceptors otomatis untuk menyisipkan Bearer token autentikasi dan penanganan timeout.

---

### 5. Form Management & Validasi Skema
* **React Hook Form:** Mengelola formulir kompleks dengan performa tinggi (uncontrolled inputs) sehingga tidak memicu re-render pada setiap ketukan keyboard.
* **Zod / Valibot:** Validasi skema berbasis TypeScript end-to-end yang menjamin data input pengguna tervalidasi sebelum dikirim ke API backend.

---

### 6. Animasi & Interaksi Visual (Spring Physics)
* **Motion (Framer Motion):** Library animasi deklaratif terbaik untuk React dengan dukungan layout animations, gestur geser (*swipe*), dan transisi halaman.
* **GSAP (GreenSock):** Standar industri untuk animasi berbasis timeline kompleks dan efek scroll lanjutan.
* **React Native Reanimated:** Wajib di ekosistem React Native agar animasi berjalan mulus di UI Thread native (60–120 FPS) dengan worklets.

---

### 7. Data Visualization, Tabel & Ikonografi
* **TanStack Table:** Headless UI untuk membangun tabel data kompleks dengan fitur sorting, filtering kolom, dan virtualized pagination.
* **Recharts / Tremor / Apache ECharts:** Grafik analitik dan diagram keuangan interaktif yang responsif dan elegan.
* **Lucide Icons / Phosphor Icons:** Paket ikon vektor yang bersih, tree-shakeable, dan konsisten pada ketebalan garis (stroke 1.75–2.0) dengan target sentuh minimal 44–48pt.

## 🚀 Cara Pemasangan (Installation Guide)

MobileCraft dapat dipasang dalam hitungan detik untuk AI Agent yang Anda gunakan:

### Opsi A: Sekali Jalan via Terminal (Quick Install)
Jalankan perintah ini di root folder proyek Anda:
```bash
# Clone konfigurasi MobileCraft langsung ke proyek Anda
git clone https://github.com/Azizulakbar89/MobileCraft-Skill-AI.git .temp-mobilecraft
cp -r .temp-mobilecraft/.cursor .temp-mobilecraft/.skills .temp-mobilecraft/.windsurfrules .temp-mobilecraft/.github .
rm -rf .temp-mobilecraft
```

---

### Opsi B: Pemasangan Manual per AI Tool

#### 1. 🖱️ Cursor IDE
1. Buka proyek Anda di Cursor.
2. Pastikan folder `.cursor/rules/` ada di root proyek Anda:
   * `.cursor/rules/mobile-ui-core.mdc` (7 Pilar, sistem token warna, validasi Zod).
   * `.cursor/rules/mobile-motion-ergonomics.mdc` (Thumb-zone, safe area, spring physics).
3. **Selesai!** Cursor otomatis menerapkan aturan ini saat Anda mengedit file `*.tsx`, `*.jsx`, `*.dart`, `*.swift`, `*.kt`, `*.vue`, atau `*.svelte`.

#### 2. 🤖 Claude Code (Anthropic CLI)
1. Salin folder `.skills/` ke root proyek Anda.
2. Tambahkan baris instruksi berikut ke file `CLAUDE.md` di root proyek:
   ```markdown
   Read and strictly adhere to .skills/mobile-frontend-craft/SKILL.md for all frontend and mobile tasks.
   ```
3. Claude Code akan selalu menjalankan pipeline 4-tahap (Tokens → Layout/Safe Area → 4 UI States → Spring Physics).

#### 3. 🛸 Google Antigravity
1. Salin folder `.skills/mobile-frontend-craft/` ke workspace proyek Anda atau ke global skills folder:
   `~/.gemini/antigravity/skills/mobile-frontend-craft/`
2. Antigravity otomatis mendeteksi skill ini dan memanggil blueprint 7 pilar saat diminta membuat frontend atau aplikasi mobile.

#### 4. 🌊 Windsurf IDE (Codeium Cascade)
1. Salin file `.windsurfrules` ke root proyek Anda.
2. Cascade otomatis membaca aturan 7 pilar pada setiap generasi kode.

#### 5. 🐙 GitHub Copilot
1. Salin folder `.github/` yang berisi `copilot-instructions.md` ke repositori Anda.
2. Saran autocompletion dan chat Copilot otomatis mengutamakan komponen type-safe, touch target 44pt+, dan TanStack Query.

## ⚡ Benchmark: AI Slop vs MobileCraft

| Aspek Kode & UX | ❌ Kode Bawaan AI Slop | ⚡ Standar MobileCraft |
| :--- | :--- | :--- |
| **Warna & Palet** | Gradasi ungu-pink neon jenuh yang norak | Token palet terkalibrasi (`#080A0E`, `#121620`, `#1A1F2B`) dengan kontras APCA |
| **Fetching Data** | Raw `useEffect` + `useState` berisiko flicker | **TanStack Query** lengkap dengan skeleton loading, cache, dan retry |
| **Formulir** | 10 variabel `useState` tanpa validasi skema | **React Hook Form + Zod** tanpa lag re-render dan pesan error presisi |
| **Ergonomi Jempol** | Tombol navigasi ditaruh di pojok atas layar | **Thumb-Zone Law:** Tombol aksi utama berada di area 40% bawah layar |
| **Ukuran Sentuh** | Tombol kecil (18px–24px) sering meleset saat ditekan | Minimal target sentuh **48pt–56pt** dengan jarak padding aman |
| **Konsistensi Radius** | Sudut membulat asal-asalan | Rumus konsentris konsisten: $R_{\text{dalam}} = R_{\text{luar}} - \text{padding}$ |
| **Motion & Transisi** | Transisi CSS linear kaku | **Spring Physics** (stiffness: 300, damping: 25) responsif pada 60–120 FPS |
