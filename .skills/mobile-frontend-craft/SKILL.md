## 🚫 Critical Anti-Slop Rules per Pillar

1. **Server State (Pillar 4):** NEVER store fetched API data inside raw `useEffect + useState`! Always use **TanStack Query** or **SWR** for caching, optimistic updates, and background refetching.
2. **Forms (Pillar 5):** NEVER write unvalidated, laggy forms with 10 individual `useState` hooks. Always pair **React Hook Form** with **Zod** or **Valibot** schemas and controlled input masks.
3. **Icons (Pillar 7):** NEVER mix emoji or arbitrary icon styles. Use **Lucide** or **Phosphor** with uniform `strokeWidth` (1.75–2.0).
4. **Tables & Massive Lists (Pillar 7 & 10):** Convert desktop tables into Grouped Inset Card Lists on mobile. For lists $>100$ items, ALWAYS use **`@shopify/flash-list`** (Mobile) or **`TanStack Virtual`** (Web).
5. **Animation (Pillar 6):** Use spring physics (`damping: 15, stiffness: 300`) and native haptics rather than slow linear CSS transitions.
6. **Geometry & Tokens (Pillar 2):** Strict concentric radius formula: `Outer Radius = Inner Radius + Padding`. All metrics must use `tabular-nums`.
7. **Auth & Sessions (Pillar 8):** ALWAYS guard against concurrent 401s with a Singleton Refresh Mutex. NEVER store session tokens in unencrypted storage.
8. **Crash Isolation (Pillar 12):** Wrap complex non-critical widgets in **WidgetErrorBoundary** so 1 chart failure never yields a blank white screen.
9. **Contextual Screen Takeover (Pillar 10):** In active checkout, ride-selection, or multi-step payment flows, ALWAYS HIDE the global Bottom Navigation Bar to free up thumb-zone space.
10. **Real-World Map Engines (Pillar 10):** NEVER draw abstract gray canvas blocks for live maps. Use real cartographic tile engines (OpenStreetMap / MapLibre / Leaflet) with traffic-coded polylines.
11. **Micro-Typography Financial Hardening (Pillar 5 & 7):** Currency symbols (`Rp`) and amounts MUST NEVER wrap or split across lines. Always enforce `whitespace-nowrap`, `shrink-0`, and `tabular-nums`.

## 6-Phase Production Pipeline

Before delivering code, mentally verify:
1. **Phase 1: Architecture & Domain Selection:** Identify domain archetype (Fintech, E-Commerce, Maps, Chat, POS) and pick stack tools from the 12 pillars.
2. **Phase 2: Layout, Ergonomics & a11y:** Enforce Safe Area Insets, 4pt/8pt grid, anchor primary actions in the lower 35% thumb zone, and verify 200% font scale resilience.
3. **Phase 3: Component, State & Masking:** Implement with uncontrolled forms, typed API hooks, and input masking without cursor jumping.
4. **Phase 4: Mandatory 6 States Audit:**
   - [x] Loading Skeleton (Shimmer + BlurHash)
   - [x] Actionable Empty State (Illustration + Action)
   - [x] Error & Retry State (Non-destructive)
   - [x] Overflow Clamping & Dynamic Type Resilient
   - [x] Offline & Mutation Queue Indicator
   - [x] Granular Widget Error Boundary
5. **Phase 5: Real-Time & Security Check:** Verify silent refresh mutex, secure storage, and WebSocket deduplication.
6. **Phase 6: Zero-Slop Self-Audit:** Confirm no neon gradients, no boxes-inside-boxes, no magic numbers, and full type safety.
